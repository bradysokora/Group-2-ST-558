Task 4: Writing a Function

Creating the getIQR() function that takes in a vector of numbers and returns the interquartile range.

getIQR <- function(x){
  iqr <- quantile(x, probs = .75) - quantile(x, probs = .25)
  names(iqr) <- NULL
  return (iqr)
}

Creating the getCoefVar() function to return the sample coefficient of variation by dividing the sample standard deviation by the sample mean

getCoefVar <- function(x){
  CoefVar <- sd(x) / abs(mean(x))
  names(CoefVar) <- NULL
  return(CoefVar)
}

Creating the getSummaries() function to return the IQR and the sample coefficient of variation by calling our previous functions

getSummaries <- function(x){
  return(list(IQR = getIQR(x), CoefVar = getCoefVar(x)))

Creating our own infix function to replace the cbind() function

`%new_bind%` <- function(...){

}
