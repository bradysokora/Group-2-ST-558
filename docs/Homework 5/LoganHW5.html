Function for querying

# Queries newsapi.org and gives us information about news articles
# @param topic a string of what topic you are interested in
# @param period a string of the time period (that time to present).
#   format is year-month-day
# @param key the api key as a string
# @return returns a tibble of article information
queryNews <- function(topic, period, key){
  url <- paste0("https://newsapi.org/v2/everything?q=", topic,"&from=", period, "&sortBy=publishedAt&apiKey=", key)
  ret <- httr::GET(url) 
  parsed <- fromJSON(rawToChar(ret$content)) 
  return (as_tibble(parsed))
}

Roller Coaster Data

coaster <- read_csv("635USrollercoasters.csv", show_col_types = FALSE) %>% clean_names() %>%
  mutate(across(c("census_region", "scale", "type", "design", "inversions"), as.factor)) %>%
  mutate(age_group = factor(age_group, c("1:Older", "2:Recent", "3:Newest"), c("Older", "Recent", "Newest")))

Missing data

sum_na <- function(column){
  sum(is.na(column))
}
na_counts <- coaster |>
  summarize(across(everything(), sum_na))

names(coaster)[na_counts > 0]

There is some missing data in the top speed, max height, drop, length, duration, and make variables. These variables are mostly data about the specifications of the rides (how long it is, length of drops, speed). Make is missing from some of the rides.
